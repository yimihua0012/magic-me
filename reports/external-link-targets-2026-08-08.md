## Submission Copy Variants

### 60-Character Tagline

AI headshots and free ID photo tools for work profiles.

### 120-Character Description

Create AI headshots and edit ID, resume, and profile photos with free browser tools for crop, resize, background, and print layouts.

### 250-Character Description

Magic-Headshot helps users create professional AI headshots for LinkedIn, resumes, and business profiles. It also includes free photo tools for ID photo crop, background color change, image resizing, file-size reduction, and printable photo sheets.

### Free Tool Pitch

Magic-Headshot offers a free browser-based ID photo tool that helps users crop a portrait, change the background color, resize the image, and create a printable photo sheet for passport-style, resume, student ID, and exam photos.

### Resume Resource Pitch

We published a practical resume photo size guide with cm, pixel, and crop references for job seekers preparing CVs, LinkedIn profiles, and international applications. It may be a useful supporting resource for readers who need to prepare a clean professional photo.
